## Outstanding external acceptance

- Apple Developer configuration is absent (confirmed by the user). Apple sign-in
  remains hidden unless both the build flag and server credentials are configured.
  Synthetic signed-token tests do not establish a real Apple login.
- Physical iPhone background-upload scheduling, locked-screen transfer, network
  recovery, and cancellation need device acceptance. Compilation and JS resume
  tests do not establish URLSession behavior on a physical device.
- The privacy contact currently uses the existing public repository support page.
  Choose a verified private contact address before App Store submission.
- Apply `0011_mobile_accounts.sql` and deploy the backend before distributing this
  mobile build: consent/account/Apple endpoints require that migration.
- Recheck voice and audio lifecycle on a real device following the Scene migration.
